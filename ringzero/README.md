# RingZer0 CTF Solves

This contains my RingZer0 CTF notes, walkthroughs, scripts, extracted artifacts, and challenge solves.

## Structure

- `Forensics/` - forensics writeups, artifacts, and recovery scripts, more to be added
- `attachments/` - per-challenge images used by walkthroughs.
- `artifacts/` - per-challenge command output, extracted metadata, or supporting evidence.
- `solve.py` or similar scripts - small helpers used during solving when useful.
